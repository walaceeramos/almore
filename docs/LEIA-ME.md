# Documentação

Falta aqui o `PLANEJAMENTO.md`, que é o documento técnico completo do projeto:
modelo de dados de todas as fases, regras de negócio, telas, fluxo de navegação
e as decisões já tomadas.

Para colocá-lo neste lugar: abra o documento "Plataforma de Treinos —
Planejamento Técnico" no Claude, exporte em Markdown e salve o arquivo nesta
pasta com o nome `PLANEJAMENTO.md`.

Sem ele, quem continuar o projeto vai improvisar decisões que já foram tomadas.
